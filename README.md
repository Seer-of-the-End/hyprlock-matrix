## Features

- Large centered time.
- Custom welcome text.
- Minimal input field with sharp corners.
- Fastfetch output in the corner.
- Green terminal-style layout info.
- Custom wrong-password message.

## Installation

1. Copy `hyprlock.conf` to:
```bash / zsh
~/.config/hypr/
```

2. Make sure your wallpaper path is correct.
3. Install required fonts:
   - JetBrains Mono Nerd Font

4. Run `hyprlock`.

## Notes

- This theme is based on my own setup and customized by hand.
- You can edit text, colors, blur, and layout to fit your desktop.
- The `fastfetch` line is used for a small system info block.
